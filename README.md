> 🎯 Exploratory Data Analysis on Airbnb booking dataset
> to uncover pricing patterns, demand trends & room type insights.

---

## 📊 Key Analysis
- 🏠 Room type demand distribution
- 💰 Price distribution by location & room type
- 📅 Seasonal booking trends
- 🌍 Neighbourhood wise availability analysis
- ⭐ Review patterns & customer behavior

---

## 💡 Key Insights
- Entire home/apt = most expensive room type
- Manhattan = highest priced neighbourhood
- Booking demand peaks in summer months
- Private rooms offer best value for money
